## กฎประกอบที่ใช้ร่วม (ตัดสินใจโดยทีมพัฒนา — แจ้งเจ้าของแล้ว ไม่ใช่ logic ภาษี)

- "บริการ" vs "สินค้า" ดูที่บรรทัดเอกสาร (`document_lines.item_kind`) — ค่าเริ่มต้นมาจากสินค้า/บริการที่เลือก
- การโอน VAT ยังไม่ถึงกำหนด ตอนรับ/จ่ายบางส่วน: `round(VAT เลื่อนที่ยังเหลือ × ยอดที่ชำระครั้งนี้ ÷ ยอดค้างชำระก่อนครั้งนี้, 2)` — ครั้งที่ชำระครบโอนส่วนที่เหลือทั้งหมด (ไม่มีเศษค้าง)
- คำนวณต่อบรรทัด ปัดเศษ half-up 2 ตำแหน่ง (spec ข้อ 2):
  - แยก VAT: ฐาน = จำนวน × ราคา − ส่วนลด, VAT = ฐาน × อัตรา
  - รวม VAT: VAT = ยอด × อัตรา ÷ (100 + อัตรา), ฐาน = ยอด − VAT
  - หัก ณ ที่จ่าย = ฐาน (ก่อน VAT) × อัตรา
- หัก ณ ที่จ่ายของใบแจ้งหนี้/บิลเชื่อ ลงบัญชีตอนรับ/จ่ายชำระ (ตาม posting rules ใน spec) — ส่วนขายสด/ซื้อสด ลงทันที
- ใบลด/เพิ่มหนี้ต้องอ้างอิงใบแจ้งหนี้ (`ref_document_id`) — ใบลดหนี้ของขายเงินสดยังไม่รองรับใน M4
- สิทธิ์: post เอกสาร = owner/admin/accountant/staff; void = owner/admin/accountant
